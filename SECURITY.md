# Security

This project ingests public market data (Binance) and trains trading agents on it. It places no orders: no service calls an order-execution API.

See [docs/security/practices.md](docs/security/practices.md) for security practices and [docs/security/](docs/security/) for the full index.

## Reporting a Vulnerability

Do not open a public issue. Report privately by email: `docteur.turboss@gmail.com`.

- Acknowledgement within 72 hours
- Responsible disclosure: please allow a fix before publishing details
- Priority categories: see [High Priority Vulnerability Categories](docs/security/practices.md#high-priority-vulnerability-categories)
