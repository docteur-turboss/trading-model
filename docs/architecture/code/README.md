# Code Documentation

This folder contains **HTML** documentation auto-generated by [TypeDoc](https://typedoc.org/)
from JSDoc comments in the monorepo's TypeScript source files.

The rendering matches [discord.js](https://discord.js.org/docs/packages/discord.js/main)
— sidebar navigation, full-text search, visibility filters, light/dark theme.

## Generation

```bash
npm run docs:generate          # Generate full HTML documentation
npm run docs:generate:dry      # Preview modules without generating
```

## Script

`scripts/generate-docs.mjs` — runs TypeDoc for each package and service, then
generates a root `index.html` listing all modules.

## Prerequisites

- TypeDoc is installed as a monorepo dev dependency
- Node.js 20+
- TypeScript 5.8+

## Hosting

Documentation is auto-generated during release and deployed to **GitHub Pages**.
See `.github/workflows/release.yml` for the deploy-docs job configuration.
