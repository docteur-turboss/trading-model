# Operations

This directory contains operational runbooks for the Trading Model platform.

## Contents

| Document                        | Purpose                                                    |
| ------------------------------- | ---------------------------------------------------------- |
| `runbook-service-down.md`       | Recovery procedure for any service crash or unavailability |
| `runbook-database-failover.md`  | Database failover and recovery (MySQL, MongoDB, Redis)     |
| `runbook-ca-compromise.md`      | Certificate Authority key compromise incident response     |
| `runbook-message-bus-outage.md` | Message bus / message-manager outage recovery              |
| `runbook-certificate-expiry.md` | mTLS certificate expiry prevention and recovery            |
| `runbook-data-corruption.md`    | Data corruption detection and recovery                     |
| `runbook-deployment-failure.md` | Failed deployment rollback procedure                       |
| `incident-response.md`          | General incident response process and escalation matrix    |
| `on-call.md`                    | On-call procedures, rotation, and contact information      |
